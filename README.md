# Projeto-Pratico-Pipeline-de-CI-com-GitHub-Actions
O projeto é parte de Gerência de Configuração de Software (GCS) e tem como objetivo demonstrar na prática o conceito de Integração Contínua (CI) — automatizar a validação do código a cada commit, garantindo rastreabilidade, reprodutibilidade e qualidade, conforme exigido pelo MPS.BR Nível F e CMMI Nível 2.
